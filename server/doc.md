===============(server)=================
* A server's main job is to serve other computers (called clients)
  by giving them what they ask for.

==========> what's servers do:
1- Web Servers:
* Store website files and send them to your brower when you visit a website
* like a waiter whi brings you a menu (webpage) when you walk into a restaurant.
2- File Servers:
* Store files and share them with other computers.
* Like a librarian who keeps books organized and hands them out when people ask.
3- Game Servers:
* Host multiplayer games
* Like a playground supervisor who keeps track of all the kids playing together
4- Database Servers:
* Store and organise large amounts of data.
* Like a filing cabinet manager who knows exactly where every document is.

==========> A server can be :
    * Physical: an actual computer, usually bigger and more powerful than
      regular PCs
    * Virtual: Software running on a computer that a acts like a separate server.

==========> How it works in real life:
* Your computer (the client) sends a request: "Hey, I want to see cats.com!"
* The server for cats.com receives this request
* The server finds the website files
* The server sends these files back to your computer
* Your browser shows you the website

==========> Servers need to be:
* Always on (24/7 availability)
* Reliable (doesn't crash easily)
* Powerful (can handle many requests at once)
* Secure (protected from hackers)
