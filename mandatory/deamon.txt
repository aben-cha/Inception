=====> how docker deamon work ?
* Definition : is the core component of the docker architecture, it runs as
  a background service and is responsible for managing docker
  objects like containers, images, networks and volumes, it communicates
  with docker CLI(Command Line Interface) or API requests to perform tasks
  such as building images starting/stopping containers, and managing 
  storage or networking.

* how it work:
  1- Startup:
    * the deamon starts when the docker service is inisialized
    * on linux is often runs as a systemd service(systemctl start docker)
      While on Windows or MAcOs it can run via Docker Desktop.
  2- Client Daemon Interaction:
    * The Docker CLI sends commands to the daeomon via a REST API.
    * By deafult, this communication occurs ove a Unix socket(/var/run/docker.sock)
      or optinally a netwrok interface for remote management.
  3- Container lifecycle:
    * The Deamon uses a container runtime like (containerd) to start and 
      manage containers.
    * it interacts with the linux Kernel to isolate containers and 
      manage resources.
  4- Image management:
    * The daemon pulls and stores images from registries like Docker Hub.
    * It handles image layering and ensures that images are reusable 
      to optimize storage and performance.
  5- Orchestration:
    * For multi-container setups, the deamon can integrate with Orchestration
      tools like Docker Compose or Kubernetes.
  6- Networking:
    * the deamon creates and manages netwrok interfaces for containers, 
      enabling communication between containers and external netwroks.
* it is a good idea to use Docker deamons:
  1- simpilified depoyment
  2- Efficiency
  3- Scalability
  4- Extensibillity
  5- Portability

===========> Container WordPress + php-fpm:
* PHP-FPm : stands for PHP FastCGI Process Manager
  1- php : used to create dynamic websites(like wordpress or e-commerce stores).
  2- FastCGI: this is a way for web servers(like Nginx or Apache) to talk to PHP, when
     someone visits your website, the server needs to ask PHP to generate the page.
     FastCGI is the messenger that makes this communitions fast.
  3- Process Manager: imagine php scripts as workers, the process manager is the 
     manager who hires workers (processes), assing them tasks and ensures they're 
     not overworked
  Why Is PHP-FPM Important?
    1- Faster for busy websites:
      instead of starting a new PHP worke for every request PHP-FPM keeps someone
      ready in the backgroung, this saves time and makes the website faster
      
* Wordpress need database, without it wordpress would be just static HTML.
